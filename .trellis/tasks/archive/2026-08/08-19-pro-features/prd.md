# 新增无标题栏窗口支持、Esc 黑名单与透明度调整（含设置界面）

## Goal

为 CClose 新增三项功能（原版 CClose Pro 能力），并提供完整的「高级设置」对话框用于配置。三项功能与设置界面共享配置基础设施，作为一个复杂任务实现。

## Requirements

### R1. 高级设置对话框（完整）
- 从托盘右键菜单新增「设置」项，打开高级设置对话框（模态式、模型内自包含 Win32 控件，无资源文件）。
- 对话框包含：
  - 功能开关复选框：标题栏中键关闭、右键最小化、长按置顶、双击 Esc、Ctrl+滚轮调整透明度
  - 「标题栏例外列表（工作区）」组：ListBox + 添加/删除按钮 + 手动输入框
  - 「Esc 黑名单」组：ListBox + 添加/删除按钮 + 手动输入框
  - 「窗口信息」拾取区：标题/类名/程序/进程四个只读字段 + 「跟随鼠标」复选框，实时显示光标下窗口信息
  - 确定 / 取消按钮
- 中英文双语（新增字符串必须同时进 lang.zig 的 EN 与 ZH 分支）。

### R2. 支持无正常标题栏的窗口（例外列表→工作区语义）
- `titlebar_exceptions` 列表语义从「排除」（跳过功能）改为「工作区」：列入该列表的窗口，标题栏功能（中键关闭/右键最小化/长按置顶）作用于**整个窗口表面**，不再依赖 WM_NCHITTEST 命中标题栏。
- 保留 ini 键名 `TitleBarExceptionList` 以兼容已有配置。

### R3. Esc 黑名单可设置
- 双击 Esc 关闭前台窗口的逻辑已存在（`kbdHookProc` 对黑名单窗口跳过）。
- 本任务提供设置入口：在设置对话框中管理 `esc_blacklist`（添加/删除），并确保写入 ini 后重启仍生效。

### R4. 窗口透明度调整（Ctrl+滚轮）
- 按住 Ctrl 在目标窗口上滚动鼠标滚轮调整其不透明度：
  - 目标 = 光标下窗口（`WindowFromPoint`）。
  - 滚轮上滚增透明、下滚减（或反之，取直观方向），每格步进约 15（0–255 标度）。
  - 范围钳制，避免完全不可见；读取当前值作为增减基准（`GetLayeredWindowAttributes`）。
  - 通过 `WS_EX_LAYERED` + `SetLayeredWindowAttributes(LWA_ALPHA)` 应用。
  - 该手势启用时**消费**滚轮消息（不再传递给目标程序），避免浏览器等同时响应 Ctrl+滚轮。
- 新增配置项 `EnableTransparency`（ini 键 `EnableTransparency`，默认开）。

## Constraints

- Zig 0.16.0、Windows 子系统、自包含 Win32 绑定（新增 extern 一律加进 `src/win32.zig`，`callconv(.winapi)`，不依赖 `std.os.windows`）。
- 不引入第三方依赖；不改 `build.zig` / `build.zig.zon`。
- 保持仓库手写格式化风格，不运行 `zig fmt`。
- 设置对话框用 CreateWindowExW 手写控件，不引入资源（.rc）体系。
- 既有配置 ini 键名保持兼容；新增键默认值不影响老用户。

## Acceptance Criteria

- [ ] `zig build`（Debug）与 `zig build -Doptimize=ReleaseSafe` 通过。
- [ ] 托盘右键菜单出现「设置」，点击弹出高级设置对话框（中英文正确）。
- [ ] 例外列表改工作区语义：把某无标题栏窗口的类名加入列表后，长按该窗口任意位置 1 秒可切换置顶并弹提示；中键/右键亦作用于整个表面。
- [ ] 双击 Esc 对黑名单窗口不关闭、对非黑名单窗口正常关闭；设置对话框可增删黑名单项并持久化到 ini。
- [ ] Ctrl+滚轮：在某窗口上按住 Ctrl 滚动，窗口透明度平滑增减并被钳制；滚轮消息不传递给目标程序；开关关闭后无效果。
- [ ] 设置对话框的「跟随鼠标」窗口信息实时更新（标题/类名/程序/进程）。
- [ ] 配置经 ini 往返正确；重启后生效。
- [ ] 未改动 `build.zig` / `build.zig.zon`。

## Notes

- 三个功能共享设置对话框与配置，故作为一个任务；实现阶段分模块推进，提交时按逻辑分组并可拆分为多个提交（提交前逐一征求确认）。
- 交互类验收（长按置顶、透明度等）无法在此环境自动模拟，除构建与自动化冒烟外，需手动验证。
