# 跟随鼠标：光标回到对话框时保留上次选中窗口

## 背景 / 问题

设置对话框的「跟随鼠标」窗口信息（`updateWindowInfo`，每 80ms 定时器）把光标所在窗口
当作当前选中窗口并刷新显示。用户悬停目标窗口时能看到信息，但要把鼠标移回对话框点击
「确认」/「添加到黑名单」等按钮时，`g_picked` 立刻被覆盖成对话框自己，刚查看的信息丢失。
两者互斥，体验差。

## 需求

1. 悬停外部窗口 → 跟随显示其标题/类/进程信息（现状不变）。
2. 光标移回设置对话框（或其子控件）→ **保留**上一个外部窗口的选取与显示，不再覆盖。
3. 可正常点击「确认」「添加到黑名单」「添加到例外」等按钮。
4. 不改变对话框布局、控件、其他功能。

## 技术方案

`src/settings.zig` `updateWindowInfo()`：取到光标所在顶层窗口 `root` 后，若
`root == g_hDlg`（光标在对话框自身/子控件上），直接 `return`，保留上一次 `g_picked`
与显示；否则照常更新。

## 验收标准（AC）

- [ ] `zig build` 通过。
- [ ] 打开设置 → 勾选「跟随鼠标」→ 悬停外部窗口：信息正确显示。
- [ ] 光标移回对话框任意位置：显示仍为刚才的外部窗口（非对话框自身）。
- [ ] 移回后能点击「确认」正常关闭对话框。
- [ ] 悬停另一个外部窗口：信息随之更新。
